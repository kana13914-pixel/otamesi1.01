## プロジェクト概要

キィニチくん専属マネージャーアプリ。iPhoneのホーム画面に追加するPWA。ユーザーの生活全般（仕事・食事・入浴・歯磨き・睡眠など）を把握し、必要なタイミングでキャラクターが自発的に声を掛ける。単なるスケジュール管理アプリではない。

## 技術構成（決定事項・変更禁止）

| 役割 | 技術 |
| --- | --- |
| アプリ形式 | PWA（ホーム画面に追加して起動。App Store配信はしない） |
| 画面 | HTML / CSS / JavaScript |
| 通知 | Pushover または ntfy（どちらかは `docs/decisions.md` で選定） |
| ローカル保存 | localStorage / IndexedDB（主）＋ GAS経由でGoogleスプレッドシートに同期（従） |
| データ処理 | Google Apps Script（GAS） |
| 予定管理 | Googleカレンダー連携（GASから読み書き） |
| 会話の作り方 | ハイブリッド：定型の挨拶・催促はセリフ集（`data/dialogue_template.yaml`）、相談・提案の場面のみLLM |
| LLM呼び出し | 必ずサーバー経由。APIキーをクライアント（PWA）側に置かない |

この表を変更したい場合は、先に `docs/decisions.md` に理由を追記してから本ファイルを更新すること。無断で変更しない。

## キャラクター（キィニチくん）の振る舞い

関係性は「上司くらいの温度感」。以下を守る。

- 状況を把握したうえで指摘・催促をしてよい
- ユーザーが疲れているときは無理をさせない
- 過剰に褒めない。常に励まし続けない
- 最終判断はユーザーに委ねる（キャラクターが代わりに決定しない）
- 自発的に声を掛けてよいが、頻度は予定・状況に応じて抑える。無差別な通知連打は禁止

## 作業ルール

- 小さい単位で作り、都度コミットする。1コミット＝1つの検証可能な変更
- 各段階の後に、人間が実機で確認できる手順（URL、操作、期待される結果）を `docs/roadmap.md` の該当タスクに書き足す
- 仕様や会話内容に迷ったら、`docs/spec.md` と `docs/decisions.md` を先に確認する。それでも判断できない場合は作業を止め、`NEEDS_HUMAN.md` に追記してユーザーに判断を仰ぐ
- 新しい決定をしたら `docs/decisions.md` に理由とともに記録する

## 禁止事項

- 原神「キィニチ」の公式立ち絵・音声・ボイスの流用（似せた合成音声を含む）
- APIキー・認証情報をクライアント側コード、リポジトリ、ログに置くこと
- プロジェクトフォルダ外のファイルを変更すること
- 破壊的な操作（force push、履歴の書き換え、無断でのファイル削除）
- ユーザーの許可なく外部サービスに課金が発生する操作を行うこと

## 止まって人間に聞く場面

以下は人間でなければ完了できない。作業を止め、`NEEDS_HUMAN.md` に依頼内容を書くこと。

- iPhone実機での通知許可・ホーム画面追加・動作確認
- Pushover / ntfy のアカウント作成、APIキー発行
- Google（スプレッドシート・カレンダー）の認証・権限設定
- キャラクター素材（立ち絵・音声）の用意
- 課金を伴う判断
